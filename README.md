# ecommerce-sales-analysis
Análise de vendas de um e-commerce americano utilizando SQL Server, Power BI e modelagem em estrela. O projeto responde perguntas de negócio sobre receita por região, desempenho por categoria de produto, segmento de clientes e evolução do faturamento ao longo do tempo. Simulando uma análise comercial real para apoio à tomada de decisão.
